# Parauga atskaite

Šeit nonāk `claude-security` atskaite no pasniedzēja mēģinājuma. Izmantojiet to, ja jūsu skenēšana nepaspēja vai neizdevās.

Lejupielādējiet to **tikai tad, kad jūsu skenēšana ir beigusies vai apturēta**:

```
make paraugs
```

Pēc tam atveriet `paraugs/CLAUDE-SECURITY-RESULTS.md`.
